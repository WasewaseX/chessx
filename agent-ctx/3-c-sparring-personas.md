## Created
1. **`src/lib/chess/sparring-roster.ts`**
   - `SparringPersona` = `{ level, id, name, flavor (max 6 words; ours ≤5), elo, style: 'solid'|'aggressive'|'tricky'|'positional'|'chaotic', blunderProne, noiseChance }`. `SPARRING_ROSTER` maps 1:1 onto the existing BOTS (names/id kept on purpose: `GameRecord.botName` stores the bot name, renaming would orphan history). Flavor/style per bot's real character (e.g. Pip "Pure vibes, zero plan." chaotic; Sentry "Never attacks, never misses." solid; Fortress "Builds walls, waits, wins." positional; Tactician "Forks, pins, skewers, repeat." tricky). All original names/text — chessigma's example names (The Wall, The Speedster, The Professor… in Part 1) were treated as forbidden and not used.
   - Elo badge = the bot's existing fixed rating (monotonic 350→2600). Deliberate deviation from the brief's "400 to 2200": est.-Elo math, PGN headers and the current picker all use these numbers; a second, different figure on the card would contradict the game.
   - `blunderProne = level <= 6` per brief; `noiseChance` surfaces the existing `bot.blunder` (0.55→0.06 for those levels). Engine behavior untouched (same values still sent to /api/engine/move).
   - `titleCards`: keys win-checkmate / win-time / win-resignation / loss / draw, 3 original variants each + `titleCardFor(result, reason)` with repeat-avoidance (reason regex maps time|flag → win-time, checkmate → win-checkmate, else win-resignation).
   - `progressFor(level, games)` → `{ wins, losses, draws, played, unlocked }` from real rows. `unlocked` is ALWAYS true with a comment: the current lobby never gated bots, so the port preserves that and shows progress badges instead ("never lock something that is currently unlocked"). `nextUpLevel(rows)` expresses the brief's unlock rule (previous level has ≥1 game) as a "Next up" badge.
