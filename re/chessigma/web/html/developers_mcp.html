Developers / MCP

Chessigma MCP server

Chess tools for Claude, ChatGPT and any MCP client. Ask about an opening, name the opening of your moves, check a position, summarize a game, open a move-by-move review, solve the daily puzzle or estimate a rating change. No sign-in, nothing to install.

Add to ClaudeSee the tools

Server URLhttps://www.chessigma.com/api/mcp

Connect

Claude (web, desktop and mobile apps)

  1. 1Click Add to Claude to open Chessigma in Claude's connector directory, or search for Chessigma in Customize > Connectors.
  2. 2Add it. There is no account to connect and nothing to sign in to.
  3. 3In a chat, turn it on from + > Connectors, then ask a chess question.

Claude Code

claude mcp add --transport http chessigma https://www.chessigma.com/api/mcp

ChatGPT and other MCP clients

Add a remote server with the URL above. Transport: Streamable HTTP. Authentication: none.

Tools

Opening Guideget_opening_guide

Chessigma's guide to an opening by name: main line, key variations and the ideas for each side. Popular openings have a full guide; any of about 3,700 catalogued names returns its ECO code and moves.

Identify Openingidentify_opening

Names the opening of a move sequence or PGN: ECO code, how long it followed theory, and the first move that left it.

Analyze Positionanalyze_position

Reads a FEN: side to move, check, mate or stalemate, every legal move, the material count and the opening name. Links open the position on the analysis board, where Stockfish runs in your browser.

Analyze Gameanalyze_game

Summarizes a PGN: players, result, opening, how the game ended and the final position, with a link that opens the game on the analysis board.

Review Online Gamereview_online_game

Turns the link of a public Chess.com live game or Lichess game into a link to its move-by-move review on Chessigma.

Get Daily Puzzleget_daily_puzzle

Today's puzzle, or any day's since 1 January 2024: the position, the solution and a link to play it.

Calculate Elocalculate_elo

Estimates the rating change after one game with the Elo formula, with K-factor defaults for FIDE, Chess.com and Lichess.

Try asking

With the connector on, Claude or ChatGPT picks the right tool.

  • Teach me the Caro-Kann: main line, key variations and the ideas for both sides.
  • What opening is 1.e4 c5 2.Nf3 d6 3.d4 cxd4 4.Nxd4 Nf6 5.Nc3 a6?
  • Is Black checkmated here? r1bqkb1r/pppp1Qpp/2n2n2/4p3/2B1P3/8/PPPP1PPP/RNB1K1NR b KQkq - 0 4
  • Review this game for me: https://www.chess.com/game/live/173765478164
  • Show me today's chess puzzle and let me try to solve it.
  • I'm rated 1500 and just beat a 1650. How much Elo do I gain?

How it works

Read-only

No tool writes data, calls an AI model or fetches another site while it runs.

Engine in your browser

The tools state facts. Links open Chessigma, where Stockfish analyzes on your own device.

No account

Nothing to sign in to. The tools never see your name, email or assistant account.

The tools do not store what you send them. To limit request rates we log each request's time, method, path, IP address and user agent, and links carry utm markers so we can count visits from each assistant. Details are in the privacy policy; use is covered by the terms of service.

Troubleshooting

  • A tool returns an error. The message says what was wrong, such as an invalid FEN, an unreadable move, a link that is not a Chess.com live game or a Lichess game, or a date outside 2024-01-01 to today.
  • The connector does not connect. Check the URL ends in /api/mcp and that no authentication is set. The server is stateless and answers POST requests only.
  • Too many requests. All callers share 300 requests per minute. Wait a minute and try again.
  • Anything else. Email mehdi@chessigma.com.
